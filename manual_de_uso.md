# Manual de Uso - Cupcakes Gourmet

## Pré-requisitos
- Python 3.x instalado
- Navegador Web

## Como executar o projeto
1. Clone o repositório do GitHub.
2. Abra o terminal na pasta do projeto.
3. Instale as dependências executando: `pip install -r requirements.txt`
4. Inicie o servidor Flask executando: `python app.py`
5. Abra o navegador e acesse: `http://127.0.0.1:5000`

## Estrutura do Projeto (MVC)
- **Model:** (A ser implementado com Banco de Dados)
- **View (templates):** Arquivos HTML e CSS (Interface do usuário)
- **Controller (controllers):** Lógica de rotas em Python (Flask)
